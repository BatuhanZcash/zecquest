# Resmi Zcash logosu

Bu klasöre resmi Zcash marka kitinden indirdiğiniz dosyaları şu adlarla koyun:

| Dosya | Kullanım |
|---|---|
| `zcash-mark.svg` | Renkli/altın işaret — menü, kartlar, quiz kapakları, favicon |
| `zcash-mark-white.svg` | Beyaz işaret — koyu ve altın zeminler üzerinde (quiz kapakları) |

Dosyaları koyduktan sonra uygulama ikonlarını ve paylaşım görselini yeniden üretin:

```bash
npm run brand
```

Dosya yoksa arayüzde yerine sade bir "ZEC" rozeti görünür.
